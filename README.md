# 反应时钟 · ABTS / DPPH

适合手机和 iPad 的中文多管实验计时网页，无需登录，无外部字体、脚本或图片依赖。

在线使用：https://z1979647082-eng.github.io/abts-dpph-timer/

## 使用

1. 选择 ABTS 或 DPPH，设置反应时长、管数和加液间隔。在“样品命名”中逐管填写名称，例如“空白”“VC-1”“样品A-1”。名称将用于下一次操作、到时提醒和时间表；留空时显示管号。DPPH 默认 30 分钟；ABTS 需自行填写。
2. 试听“加液”和“测试”两段中文语音，确认设备音量，选择立即开始或指定开始时间。
3. 点击“开始实验”，后续加液与测试提醒自动进行，无需逐管确认。
4. 如需中断加液，点击“暂停后续加液”；继续后，尚未开始的管按暂停时长顺延。已开始的管按原定时间提醒测试。

**使用时保持页面前台、屏幕亮起。** 页面会在支持时申请屏幕常亮。浏览器后台、锁屏或关闭页面后的准时响铃无法保证。刷新后可恢复本机进度，但需再次点按启用声音；离开期间的到期提醒会补发。

实验设置与计时进度保存在本机浏览器 localStorage，不上传到 GitHub。清除浏览器数据、更换浏览器或设备会丢失本机进度。页面显示“已到测试时间”，不会把它视为人工已测试。

## 语音提醒

开始反应时直接播报“加液”，到测试时间直接播报“测试”。语音使用预先生成的普通话神经网络女声（Xiaoyi），以偏甜美、轻快的声音播报，适度提高音调并放缓语速；这是合成女声，不是《王者荣耀》妲己的游戏原声。音频随网页一起提供，不依赖设备安装中文语音，使用时无需调用在线语音服务。播放复用同一个 HTML 媒体音频元素，点试听时同步调用播放，减少手机上手势授权与 Web Audio 路径的问题。同时发生多个提醒时，逐项播报，实际播放结束后再播放下一段；失败的提醒保留待播状态，不当作播放完成。

若手机或平板仍听不到声音，展开“听不到声音？点这里检查”，直接使用原生音频控件或单独打开 WAV 录音，调高媒体音量、关闭静音并检查蓝牙输出。网页无法判断扬声器是否真的发出声音，状态显示播放完成也不代表实际听到。

样品名可重复，管号始终单独保留，便于区分平行样。名称可在实验运行中修改，不改变任何计时，并保存在本机浏览器供下次使用。

## 横竖屏切换

页面顶部“显示方向”可选择“自动 / 竖屏 / 横屏”。自动模式跟随浏览器窗口方向；手动模式会在需要时将网页画面旋转 90°，不依赖浏览器的系统方向锁定接口。可以在系统锁着竖屏时点“横屏”，再将设备横放使用。返回“自动”即可恢复随设备方向显示。

方向偏好会保存在本机。切换无需刷新，不会暂停或重置实验。手机横屏且实验正在运行时，当前时间、下一次加液和下一次测试会并排显示。

## 时间计算

- 第 n 管开始时间 = 实验开始时间 + (n − 1) × 加液间隔。
- 第 n 管测试时间 = 该管开始时间 + 反应时长。
- 使用绝对时间戳计算倒计时；支持跨小时、跨午夜、同时多个事件和暂停恢复。

## 本地验证

安装 Node.js 后运行：

```sh
node tests/timing.cjs
node tests/media-voice.cjs
node --check app.js
node --check orientation.js
```

包含跨午夜、暂停、同时到期、后台返回补发、样品命名和 JSON 恢复等 10 组计时测试，以及媒体播放的手势调用、完成事件、失败和取消测试。
